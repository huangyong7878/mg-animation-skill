# MG Studio R5 -> R0 approved R4 dispatch

This interface lists sampled-frame findings generated by previously paid
DeepSeek reviews. The project owner can inspect evidence, select specific
finding IDs, and explicitly authorize a new R4 assignment. R0's existing
`workflow.r4_dispatch.dispatch` checks candidate SHA, implementation SHA,
video bytes, approved script/voice locks and allowed edit paths.

Approval creates a new immutable `work/r4_inbox/<task>/assignment.json`.
**It does not execute Codex**, render a new video, declare full audiovisual
R5 PASS, create a GitHub issue or authorize R7 publication. The pre-existing
R4 panel must be used separately to run the approved assignment.

Findings are model-generated candidates from sampled still frames, not
verified facts. Check original video evidence before approval. Pilot 001's
existing V2 visual rework may overlap the newly suggested issues.
Do not approve duplicated work blindly.
