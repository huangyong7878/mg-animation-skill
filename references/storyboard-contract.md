# Storyboard Contract（分镜交接协议）v1.0

创意导演 → 技术导演的交接规范。技术导演有权打回不符合本协议的分镜表。

## 分镜表必须包含

### 头部元信息
- 标题
- 总时长（约数，来自配音时间轴加总）
- Beat 数量、Shot 数量
- 配音引擎（Edge TTS）及时间轴精度（句级）

### Beats 清单
每个 beat：
- 编号（B1、B2……）
- 包含的解说句子（原文引用）
- 核心语义（一句话）

### 每个 Shot
- 编号（Shot 1、Shot 2……）
- 类型：新镜头 / 延续镜头
- 覆盖的 beats（B1+B2，或 B3）
- 解说文本（该 shot 覆盖的所有句子原文）
- 画面描述（纯视觉语言，无引擎术语）
- 画面变化（随配音推进的变化点，标注触发句子）
- 延续镜头需注明：保留什么、改变什么
- 情绪意图（1~2 词）
- 转场意图（转折/延续/并列/强断，及原因）

### 时间范围
- 每个 shot 的约起止时间（来自配音时间轴，技术导演据此精确计算）

## 创意导演不许输出

- JSON、坐标、像素值
- 动画类型名（fade/pop/slide/move）
- 引擎参数（`hide_before`、easing 等）
- 具体的布局代码

## 技术导演的权利

- 字段缺失 → 打回，注明缺哪个字段
- 视觉需求超出引擎能力 → 走降级流程，不打回创意导演（除非降级后语义完全丢失）
- 时间轴精度不足（如要求词级同步但只有句级时间轴）→ 标注降级为句级，或申请 WhisperX
